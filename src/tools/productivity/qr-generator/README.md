# Generador de QR

Herramienta frontend para generar códigos QR como PNG.

## Alcance actual

- Texto libre.
- URL.
- Email.
- Teléfono.
- Tamaños de salida pequeño (256 px), mediano (512 px), grande (1024 px) o personalizado (128 a 2048 px).
- Descarga PNG.
- Validación suave sin bloquear el flujo.

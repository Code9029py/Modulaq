# Limpiador de texto

Primera herramienta real de Modulaq. Funciona completamente en frontend y expone su lógica como servicio reutilizable.

## Alcance actual

- Normalización de espacios.
- Limpieza de saltos de línea.
- Recorte de bordes.
- Normalización de comillas tipográficas.
- Eliminación de caracteres invisibles o de control.
- Estadísticas antes/después.
- Descarga del resultado como archivo `.txt` con nombre editable.

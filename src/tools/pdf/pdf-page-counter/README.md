# Contador de páginas PDF

Herramienta frontend para contar páginas de un archivo PDF sin subirlo a un servidor.

## Alcance actual

- Un archivo PDF por vez.
- Selección o arrastre simple.
- Conteo local con `pdf-lib`.
- Resultado con nombre, tamaño y cantidad de páginas.
- Errores amigables para archivos no PDF o no legibles.

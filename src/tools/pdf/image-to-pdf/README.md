# Imagen a PDF

Herramienta frontend-only para convertir una o varias imágenes PNG, JPG/JPEG o WebP en un PDF descargable.

## Alcance V1

- Carga múltiple de imágenes.
- Vista previa, nombre, formato y tamaño por archivo.
- Reordenamiento manual con controles Subir/Bajar.
- Eliminación individual y limpieza completa.
- Nombre de archivo de salida editable y sanitizado.
- Generación de un PDF local con una imagen por página.
- Ajuste proporcional de cada imagen dentro de una página A4.

## Pendiente

- Opciones avanzadas de página.
- Compresión avanzada.
- API real e integración backend.

# Reordenar paginas PDF

Herramienta frontend-only para cambiar el orden de las paginas de un PDF y descargar un archivo nuevo.

## Alcance V1

- Carga de un unico archivo PDF.
- Lectura local del documento con `pdf-lib`.
- Lista simple de paginas, sin miniaturas.
- Reordenamiento manual mediante controles Subir/Bajar.
- Restablecimiento del orden original.
- Descarga local como `<nombre-original>-reordenado.pdf`.
- Lista con scroll interno para documentos extensos.
- Errores amigables para archivos no PDF o no legibles.

## Pendiente

- Miniaturas y vista previa visual.
- Reordenamiento mediante arrastre.
- Codigo integrable, API y documentacion publica extendida.
